Sivakumar Kanithi — DevOps Portfolio (static version)

Files:
  index.html   - the whole page
  style.css    - all styling (terminal / code-rain theme)
  script.js    - background animation + contact form + footer year
  Sivakumar-Kanithi-DevOps-Resume.pdf - resume opened by the Resume buttons
  favicon.ico  - browser tab icon

How to use:
  1. Open index.html in any browser, or
  2. Upload all files (keep them in the same folder) to any host:
     GitHub Pages, Netlify, Vercel, S3 static website, etc.

Contact form:
  Powered by Web3Forms. The access key is inside index.html
  (name="access_key"). Messages go to the email registered with that key.
  The form only works when the page is served over http/https
  (it also works from a local file, but hosting is recommended).
